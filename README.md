## Projetos em destaque

### S3 — linguagem experimental de sistemas

Projeto principal em desenvolvimento privado: linguagem baseada em **ternário balanceado**, com frontend de compilador, análise semântica, IR tipada, SSA/CFG, verifier, otimizações, Assembly própria, emulador e backend nativo Linux x86-64.

O repositório principal ainda é privado. A metodologia de avaliação independente do ecossistema está disponível em **[S3-Benchmarks](https://github.com/SamDevlab/S3-Benchmarks)**.

**Áreas:** compiladores, sistemas, IR, SSA, x86-64, correção diferencial, segurança de memória.

### [Human Space Atlas](https://github.com/SamDevlab/human-space-atlas)

Atlas 3D de objetos artificiais no espaço usando **CesiumJS**, propagação orbital **SGP4**, Web Workers e dados públicos de fontes como CelesTrak, NASA, NOAA e JPL.

O projeto separa explicitamente dados observados, posições propagadas e reconstruções visuais cinematográficas.

**Stack:** React, TypeScript, CesiumJS, satellite.js, Node.js, Vitest, Playwright.

### [Molecule Generation & Virtual Screening Suite](https://github.com/SamDevlab/molecule-generation-suite)

Suite de descoberta computacional de fármacos que combina **RDKit**, **XGBoost**, fingerprints moleculares, docking com **AutoDock Vina** e exploração evolucionária de candidatos.

**Áreas:** Machine Learning, química computacional, virtual screening, ADMET/QED, automação científica.

### [Transparência Municipal](https://github.com/SamDevlab/transparencia)

Framework reproduzível para coleta e análise de dados públicos municipais com preservação de fonte, proveniência, snapshots e identidades oficiais.

Princípio editorial e técnico do projeto: **sem fonte, sem fato**.

**Áreas:** engenharia de dados, provenance, dados públicos, SQLite, pipelines reproduzíveis.

### Sistemas de decisão e automação

Também desenvolvo duas plataformas privadas voltadas a problemas operacionais reais:

- **Inteligência de Licitações — Bahia:** coleta, triagem, análise documental, tarefas, estimativas e decisões com limites explícitos de aprovação humana;
- **Radar de Importação Brasil:** descoberta multi-fonte, snapshots de mercado, sourcing, compliance, logística e recálculo seletivo de oportunidades.
